## ② 运营 Agent · 主流程

> 并行 · Loop · Hook

### 入口

```
运营人员 ──► 接入层  [鉴权 · 数据范围 · 限流 · 会话]
    │
    ├─ hook: request_start   建 Trace / 预算 / 取消令牌 / 审计
    ▼
```

### Q&A 直答层

```
Q&A 直答层  [标准问答 + 数据答案缓存]
    │
    ├─ hook: pre_route       权限桶 · 时效 · 口径 · 版本校验
    ├─ 命中 ──────────────────────────────────────────►【⑤ 交付】
    ▼ 未命中
```

### 任务理解

```
任务理解
    ├─ ⇉ 并行:改写 · 指代 · 意图
    ├─ ⇉ 并行:槽位抽取 · 情绪识别
    ├─ ⇉ 并行:记忆读取 · 历史预取 · 知识预检索
    │         (澄清判断需等待意图 + 槽位)
    ▼
```

### 执行路由

```
执行路由
    ├─ 条件不足 ─► 澄清问题 ─────────────────────────►【⑤ 交付】
    ├─ 简单任务 ─► 受控工具调用 ─────────────────────►【⑤ 交付】
    ▼ 复杂任务
```

### 上下文组装

```
上下文组装  [准入 · 压缩 · 引用 · 预算]
    ├─ ⇉ 并行:能力目录 · 相关记忆 · 证据摘要 · 历史摘要
    ▼
```

### Agent Runtime · Loop

```
┌──────────────────── Agent Runtime · Loop ────────────────────┐
│                                                              │

│                │             参数 · 权限 · 预算 · 并发控制    │

│               连续无进展 · 用户取消                           │
└─────────────────────────────┬────────────────────────────────┘
                              │ 调用
                              ▼
```

## ③ Tool / Skill 体系

| 层级 | 工具 |
|---|---|
| **Global** | `list_skills` · `read_skill` · `read_result` |
| **Skill-scoped** | `room-metrics` · `interaction-analysis` · `session-comparison` · `operations-knowledge` · `report-generation`(Shell/渲染/交付) |
| **Internal** | 凭证 · 连接 · 存储 · 权限 · 审计(不对模型暴露) |

### 渐进披露

```
list_skills(名称+描述)
    ↓
read_skill(完整说明+工具 Schema)
    ↓
激活
```

### 有效能力公式

```
有效能力 = 用户权限 ∩ Runtime 策略 ∩ Skill 声明 ∩ 当前激活范围
```

### 能力出口

| 类型 | 出口 |
|---|---|
| 指标 / 样本 / 对比 | 业务查询服务 ① |
| 知识 | RAG |
| 受限 Shell | 隔离执行环境 |
| 渲染 | 产物存储 |

## ④ Trace · 指标 · 审计

> 贯穿 ①→⑤ 全流程,含 Q&A 命中路径

### Span 结构

```
trace: request {request_id, turn_id, tenant, user_scope}
   ├─ span: access                 [auth, rate_limit]
   ├─ span: qa_cache               [cache_hit, cache_key_version]
   ├─ span: understand             ⇉ rewrite / intent / slot / emotion
   ├─ span: context_assemble       [before_tokens, after_tokens, compact_count]
   ├─ span: loop.1
   │    ├─ span: model             [model_ver, prompt_ver, tokens, cost]
   │    ├─ span: read_skill        [skill_name, skill_version]
   │    ├─ span: tool.metrics      [tool, params_digest, duration, rows]
   │    └─ span: post_tool         [admitted_bytes, result_id]
   ├─ span: loop.2 ...
   ├─ span: deliver                [artifact_id, revision, review_result]
   └─ span: end                    [total_cost, status, cancel_reason]
```

### 记录字段

耗时 · Token · 费用 · 重试 · 模型/提示词/Skill 版本 · 压缩前后大小 · 结果引用 · 证据引用 · 失败原因

### 出口

```
OTel Collector ─► Trace 存储 / Prometheus + Grafana
        审计可靠落库(不可丢)· 日志脱敏 · 完整证据进受控存储
```

### 传播

并行任务显式传递 Trace 上下文与权限上下文。

## ⑤ 统一交付

### 校验

权限 · 证据对应 · 统计口径 · 产物状态 · 敏感内容

```
    │   hook: pre_deliver
    ▼
```

### SSE 事件流

```
SSE ─► 运营人员

事件类型:
  PROGRESS · CLARIFICATION · ANSWER_DELTA · ARTIFACT_READY
  ERROR · ABORT · DONE
```

### 收尾

- 收尾:`hook: request_end`(结算 · 审计 · 指标)
- 异常:`hook: on_error` / `hook: on_cancel`(资源回收 · 取消传播)
