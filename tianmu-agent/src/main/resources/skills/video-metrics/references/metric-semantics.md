# 弹幕指标口径

当前只支持 bullet_count。它表示指定视频、指定业务日期范围内的弹幕记录数量，不代表人数；一个人发送多条弹幕会贡献多条记录。

## 时间范围

业务日期使用 Asia/Shanghai。某日范围为该日 00:00（含）至次日 00:00（不含）。只有最近 30 个已结束自然日可以查询，不能把请求时间当作数据覆盖水位。相对日期以服务端固定的 businessDate 为准。

## 数据来源

- mysql-demo-fixture：MySQL 中预置的演示记录。即使数据实际读自 MySQL，也必须标注模拟数据。
- mysql:bullet:retained-persisted-v1：只统计业务 MySQL 中当前保留、已经持久化的记录，按创建日期归属。它不证明发送中的消息已经全部入库，也不包含已经删除的历史记录。

## 回答边界

报告数据值、日期、来源及必要口径，引用 evidence_id。缺少记录不能解释成零；不完整结果不能当作完整结果交付。比较不同来源、统计版本或日期范围之前，应先确认口径一致。单一弹幕总数不足以推断互动率、观众人数或内容表现变化的原因。
