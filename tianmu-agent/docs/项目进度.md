# 项目进度

更新：2026-10-22。Agent 工程版本为 0.7.0-SNAPSHOT，当前为开发预览阶段，两个 Maven 工程分别构建。

## 已完成

- 统一 HTTP/SSE 入口：可信身份 → FAQ → 会话记忆与规则校验 → 澄清/改写/情绪三路并行 → 任务组装 → Harness。
- 单 Agent 循环、取消与终态仲裁、Hook/Gate/Transform、OTel Trace、文件 Outbox 与可选 Kafka 出口。
- Skill、Prompt、Tool Schema、FAQ 独立资源目录；classPath 资源修改后构建重启，尚无热更新。
- MySQL 权威记录、Redis 会话视图、私有文件对象，以及终态事务、幂等、重启读取与越权隔离。
- business profile：现有 JWT + Redis 在线会话、用户状态与视频归属检查、实际 SQL 查询和结果访问时再次授权。
- 首个真实指标：按日期统计当前仍保留的已入库弹幕；SQL 对账与证据一致。
- 弹幕稳定 ID、重复投递幂等、记录与计数事务、消费者异常传播。
- 开源整理：MIT、环境变量配置、贡献与安全文档、任务规格、CI 定义和免 Key Demo 冒烟；远端工作流尚待推送触发。
