10. HTTP 拒绝无凭证请求和空问题。
11. 其他用户不能读取任务状态和 SSE。
12. 终态任务的 SSE 事件可回放，含 DONE。

v0.1 初始测试结果：12 项，失败 0、错误 0、跳过 0。执行 `mvn -o -B package` 时编译和全部测试通过，
但离线打包阶段缺少少量 Boot 插件依赖；随后使用工作区 Maven 仓库补齐依赖，
执行 `mvn -B -DskipTests package` 完成可执行 JAR 打包（BUILD SUCCESS）。

## 可执行包启动与 HTTP 冒烟

使用实际打包后的 JAR，以 `127.0.0.1:18201` 启动并请求 HTTP 接口，以下全部通过：

- POST 创建任务、GET 状态，查询演示在 3 步内到达 SUCCEEDED。
- SSE 含最终 ANSWER 和唯一 DONE，Last-Event-ID 可跳过已读事件。
- 证据接口返回 value=128、demo=true，数据与任务归属一致。
