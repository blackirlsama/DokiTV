## 自动化测试

`AgentRuntimeTest` 覆盖：

1. Skill → 工具 → 答案完整执行，证据归属和模拟数据标记正确。
2. 缺少日期时返回澄清。
3. 越权视频不产生证据。
4. 未激活 Skill 无法调用专用工具。
5. 重复同参工具调用终止，避免空转。
6. 伪造证据引用无法交付。
7. 取消后不再执行或接受晚到答案。
8. 工具参数不能附带伪造租户字段。
9. 其他任务的证据 ID 无法读取。
10. HTTP 拒绝无凭证请求和空问题。
11. 其他用户不能读取任务状态和 SSE。
12. 终态任务的 SSE 事件可回放，含 DONE。

v0.1 初始测试结果：12 项，失败 0、错误 0、跳过 0。执行 `mvn -o -B package` 时编译和全部测试通过，
但离线打包阶段缺少少量 Boot 插件依赖；随后使用工作区 Maven 仓库补齐依赖，
执行 `mvn -B -DskipTests package` 完成可执行 JAR 打包（BUILD SUCCESS）。

## 可执行包启动与 HTTP 冒烟

使用实际打包后的 JAR，以 `127.0.0.1:18201` 启动并请求 HTTP 接口，以下全部通过：

- POST 创建任务、GET 状态，查询演示在 3 步内到达 SUCCEEDED。
- SSE 含最终 ANSWER 和唯一 DONE，Last-Event-ID 可跳过已读事件。
- 证据接口返回 value=128、demo=true，数据与任务归属一致。
- 其他用户无法读取任务和证据，无认证请求返回 401。
- 已成功任务再次取消保持 SUCCEEDED，不覆盖原终态。
- 缺少日期返回 NEEDS_INPUT；越权视频返回 FAILED / FORBIDDEN，不交付答案。

冒烟完成后停止临时服务。PowerShell 开发脚本通过语法解析检查。
交付压缩包只包含源码、配置、脚本和文档；可执行 JAR 另附，均不包含用户 Maven 设置或本地凭证。
