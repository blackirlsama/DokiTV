## 通过的异常与恢复场景

| 范围 | 已验证行为 |
|---|---|
| 身份与权限 | 无身份 401；跨用户读取 404；越权视频和模型生成的越权工具参数被拒绝 |
| 幂等与澄清 | 重复请求复用任务；同键不同内容 409；澄清只能消费一次 |
| 并行准备 | 三分支时间区间实际重叠；非中性情绪与合法改写被保留；慢情绪不阻塞主任务 |
| 降级 | 改写失败和擅自换视频时保留原条件；澄清失败时不进入 Harness |
| 模型与终止 | 非法决策拒绝；调用超时受控失败；在途取消产生唯一终态 |
| 进程重启 | 任务答案、历史、产物、SSE 和幂等记录仍可读取 |
| Redis 故障 | 使用不可连接的 Redis 地址启动，已有历史从 MySQL 加载，下一轮正常回答 |
| 删除与清理 | 删除后立即禁读，随后会话数据库记录与私有对象被清理 |
